# Changelog

## 0.4.0

- Added registry manifests for the Official MCP Registry, Glama, Claude Code and Gemini CLI.
- Added a Claude Code marketplace entry so the plugin installs by name.

## 0.3.0

- Removed the `get_youtube_community_images` tool.

- Renamed the comment tools to `download_youtube_comments`, `get_youtube_download`, `list_youtube_downloads`, and `get_youtube_download_file`.

- Removed the cancel and restart tools.

## 0.1.0

- Added the remote YouTube Comments Downloader MCP server configuration.
- Added export lifecycle, file URL, channel details, and community images tools.
- Added OAuth 2.1 PKCE and existing API-key installation guidance.
